# Avatar Studio

סטודיו לסרטונים אנכיים ברמת הפקה עם אווטאר דיגיטלי, שהסוכן שלך מפעיל. פלאגין ל-**Claude Code** ול-**Codex**.

- **עולמות פוטוריאליסטיים וטיפוגרפיה קינטית.** כל סצנה היא סט מצולם עם כיתוב בעברית שנוחת על המילה. האווטאר עומד בשליש התחתון ויוצא מהפריים כשצריך.
- **עולם אחר בכל סרטון.** עמוד שדרה קבוע (ריאליזם, קצב, ווליום) ועולם משתנה: חומר, אור, פלטה, פונט, כתוביות, מעברים וסאונד. מנוע היסטוריה פוסל עולמות קרובים מדי לאחרונים. לא "סרטון אנימה אחד וסרטון פיקסאר שני".
- **Cartesia כקריינות ברירת מחדל, ElevenLabs כגיבוי.** ספק אחד מקריין סרטון שלם, עם תזמון מדויק לכל מילה.
- **תמונות Cover כברירת מחדל:** 9:16, 3:4, 4:5, וריאנט עם פנים וריאנט טיפוגרפי, והקאבר מוטמע בקובץ.
- **בקרת איכות:** ‎-14 LUFS, קצב, פריימים שחורים או קפואים, גלישת טקסט וחפיפה עם הפנים של האווטאר.
- **קליפים מהירים:** `avs clip` הופך טקסט קצר לקליפ מעוצב.

## התקנה

דרישות: Python 3.9+‎, Node 18+‎, ffmpeg.

**Claude Code**
```
/plugin marketplace add <owner>/avatar-studio
/plugin install avatar-studio@avatar-studio
```
**Codex:** `./install.sh codex`

אחרי ההתקנה אמרו לסוכן: *"תכין לי סרטון אווטאר על ..."*

## מפתחות
בקובץ `~/.avatar-studio/.env`: ‏`CARTESIA_API_KEY` (קריינות, ברירת מחדל), ‏`ELEVEN_API_KEY` (גיבוי), ‏`HEYGEN_API_KEY` (האווטאר, עלות מוצגת תמיד לפני חיוב), ‏`GEMINI_API_KEY` (תמונות לסצנות). אין להדביק מפתחות בצ'אט.

בדיקה בלי מפתחות בכלל: `avs selftest`.
